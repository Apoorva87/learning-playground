Where these states sit in 64 blocks

The embedding supplies 5,120 features per text token. Each block applies its mixer and a gated MLP with a 17,408-wide intermediate. Residual connections pass the result to the next block. After 64 blocks, final normalization and a vocabulary projection produce the next-token logits.

The 48 recurrent mixers update convolution and recurrent state. The 16 full-attention mixers append one K and V per decode position. This DaCe graph begins after the cache update in block 3 and ends before the attention output gate. The shared PyTorch run covers the full chain, including the MLPs and vocabulary head. Count an edge, then count its uses

Each input memlet specifies a slice of an array. For a state, multiply its slice length by four bytes per FP32 element and by the number of map iterations. Count the inner tasklet edges once. Equal addresses accessed by different iterations count again.
