    OpenMAIC

    What it does. Give the app a topic or upload your reading to create a live, interactive classroom. An AI teacher can explain a slide aloud, draw on a shared whiteboard, and answer your questions. AI classmates can join the discussion.

    Lesson creation, activities, and export options
    • Build a course. Plan and edit the outline, reuse uploaded materials, research a topic on the web, and revise slides by hand or with an agent.
    • Practice. Generate quizzes, simulations, games, mind maps, 3D models, or coding exercises. A project-based tutor can guide you through milestones.
    • Teach and share. Run a lecture, Q&A, or roundtable debate. Replay the course or export it to PowerPoint, offline HTML, a classroom ZIP, or video with the optional renderer.
    • Use it from other tools. An agent integration can request a classroom from an IDE or messaging app. The generation SDK can produce individual lesson activities.
    OpenMAIC feature guide

    What we used · Nov 23, 2026. We ran the generation SDK with a local Qwen model. It produced a KV-cache calculator and four quiz questions. We fixed the calculator controls and English labels, edited the quiz, and wrote the walkthrough around them.

    Classroom status. We attempted to start the full app, but the session could not access Docker. Live teaching, class discussion, speech, and whiteboard interaction are still untested here.

    Try it. Open the calculator, choose Double Tokens, and check your memory prediction. Then take the quiz.

    Understand-Anything

    What it does. Point the tool at a code repository, a wiki of linked notes, or a Figma file. It builds a graph of how the pieces fit together. Open the dashboard to search, select an item, follow its connections, or take a guided tour.

    Code, knowledge-base, and design workflows
    • Explore code. Map files, functions, classes, and dependencies. Ask questions about the project, get an explanation of one function, or generate an onboarding guide.
    • Understand changes. See which parts of a system a code change affects, trace business processes across the code, and update the graph as files change.
    • Explore notes. The knowledge-base skill follows links between articles and uses an agent to identify claims, named entities, and connections the author left implicit.
    • Explore designs. The Figma skill maps screens, components, instances, and design tokens so you can trace where a design element is reused.

    Socratic Workshop

    What it does. Bring a topic, paper, or set of notes to a conversation. The tutor asks one question at a time, listens to your explanation, and uses your answer to choose the next question or hint.

    Practice, progress, and visuals

    You can ask for a hint, a direct explanation, or an interactive figure. As you practice, the tutor tracks skills, checks recall, and asks you to apply an idea to a new situation. You can save the session and resume it later.

    What we used · Nov 24, 2026. We started its source-based workshop in Codex with the shared field guide. The first question asks what a model can reuse after it reads a clue about a key in a drawer. The saved page contains the actual opening turn. The live conversation continues in chat.

    Try it. Answer the question in your own words, even if you are guessing. The tutor needs your answer before it can assess a skill or tailor a hint.

    DeepTutor

    What it does. Ask a tutor a question and give it material to teach from. You can use chat from the command line or open the learning workspace to study and organize material over time.

    Study modes and learning records

    DeepTutor offers knowledge-base search, guided learning paths, practice quizzes, research, visualization, and math animation through optional modules. It can also keep sessions, reading material, notebooks, and learning memory.

    What we used · Nov 24, 2026. DeepTutor’s command-line chat and a local Qwen model produced a full answer from our prompt and field guide. The answer got the memory arithmetic right but applied the toy model’s 32 layers to DeepSeek. The reviewed lesson flags the error and links to the original answer.

    Try it. Read the worked attention example, then cover the answer and predict what doubling the token count does to memory. This trial used one chat turn. The full web workspace, retrieval, quizzes, and personalized learning paths are untested here.

    Visual Explainer

    What it does. Ask an agent to explain a process or comparison visually. It chooses diagrams, charts, and step-by-step figures, then renders the explanation as a browser page.

    Model architecture and cost

    HuggingArch

    Choose a bundled model in the hosted explorer or run the local CLI against its architecture specification. Pick a sequence length and inspect the operations and cache sizes the model requires. The linked guide also covers bringing a new Hugging Face model to the tool.

    What we tried. We compared Llama 3.2 1B and DeepSeek V4.1 Flash with the local engine. The Flash result separates 890 bytes per token on average from 2,727,936 bytes of bounded state. The worked example shows why adding a single token can cost more or less than 890 bytes.
