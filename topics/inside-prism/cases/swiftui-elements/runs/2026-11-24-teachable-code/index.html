Try reading a change yourself

On Browse, move the white ring to another movie. Before pressing Select, predict which title will open. Try hiding the captions. Can you still open that movie?

Check your explanation. The focus style draws the ring. The grid passes an action to each poster. Activating the poster opens its title. The caption has its own condition inside the button, so hiding the text leaves the button active.
