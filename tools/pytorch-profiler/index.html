Read a nested call

A host interval begins as PyTorch enters a recorded operator and ends as it leaves. Child operations occupy part of their parent’s duration. In this measured example, a grouped convolution from the first decoder block fills most of the selected interval.

Inside this run

The checkpoint contains 64 decoder blocks. The study profiles a 16-token prefill and one cached decode on eight CPU threads. A separate one-thread grouped-query attention replay uses the fourth block’s captured tensors. Switching between the three labeled captures changes the operator timeline and rankings.

Try the trace explorer

  1. Open cached decode and select Per-channel convolution. Inspect the input shapes for one small backend call, then select its enclosing call.
  2. Under Where the time went, count within grouped convolutions and choose Calls. Search for _slow_conv2d_forward to see how 10,240 channels across 48 recurrent blocks produced 491,520 calls.
  3. Select Attention replay. Click Mix values in the dependency diagram to open the final matrix product. Compare its measured duration with its two input sizes.
  4. Inspect the first two allocation events. Each repeated KV tensor adds 417,792 bytes. Change the output head and feature to compare the profiled replay and the source fixture.

Instrument a function of your own

from torch.profiler import profile, ProfilerActivity, record_function

with profile(activities=[ProfilerActivity.CPU], record_shapes=True) as p:
    with record_function("decoder/my_function"):
        output = my_function(inputs)

print(p.key_averages().table(sort_by="self_cpu_time_total"))
p.export_chrome_trace("cpu-trace.json")

PyTorch supplies operator durations, optional tensor shapes, CPU allocation events and Chrome-trace export. This study adds block markers, a second execution-trace observer for tensor metadata, a reader for the large captures, a browser timeline and a numerical comparison. The full-model run sampled CPU operator ranges. Device kernels, memory-controller traffic and worker-level scheduling require other capture methods. Official profiler tutorial
