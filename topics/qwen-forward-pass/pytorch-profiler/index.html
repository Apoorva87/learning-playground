How much CPU ran?

A separate pass measured wall and process CPU time around the same modules with lightweight hooks. Process CPU sums time across all threads. Dividing by elapsed time gives the average number of busy CPU cores attributable to the process during this interval.

Eight intra-op threads were configured. The timeline shows the main host thread. It cannot identify which workers overlapped or when they ran. The instrumented range comes from a separate invocation with both Kineto and the execution trace observer enabled. Explore the separate 50 ms CPU occupancy samples.
