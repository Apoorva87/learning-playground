Learning playground

A notebook for trying tools on real learning tasks and remembering which parts helped.

Topics Learning questions, shared inputs, and worked examples from each tool. → Tool catalog Repositories, skills, and agents with their tested versions and setup recipes. → Preferences What I would use again, for which task, and the examples behind that decision. →

How it fits together

A topic owns the example and its inputs. Each tool gets a separate attempt at that example, so you can compare the results side by side. Feedback stays with the attempt. The preferences log links back to it when you decide what to keep.

Git keeps the examples and installation recipes. Run ./install.sh to recreate the tools in .local/tools/.
