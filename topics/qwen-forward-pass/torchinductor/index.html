      Rounding and numerical checks

      The eager outputs matched every saved reference value exactly. Compiled attention passed an absolute tolerance of 10⁻⁶ plus a relative tolerance of 10⁻⁵. For the MLP we used an absolute allowance of 0.003 plus 0.016 times the magnitude of each reference value. The generated pointwise loop computes SiLU and the product in FP32 before storing BF16. Eager SiLU returns a BF16 intermediate. Inspect exact-match counts and root mean square error in each run record.

      Reading byte counts and parallelism

      Each tensor entry gives its element count times its dtype width. A tensor can appear as both an input and an output when the kernel reuses storage. A cache can satisfy repeatedly issued loads. These measurements contain no hardware traffic counters or library-internal worker timeline. The emitted C++ has vector lanes and zero OpenMP parallel regions. The external library calls have their own implementations.
