Inside Prism

Start with something you can see on an Apple TV screen. Which lines draw a movie poster? Which ones respond when you move the remote or press Select?

Explore the screen

Open the interactive screen sketch. Click a poster to find the artwork and caption. Move the focus ring to a different title, hide its caption, then press Select. Each action reveals the Swift responsible and explains the design choice.

Follow the code

The fourteen-step guided map moves from the app window through the six tabs, grid, poster, playback controls, and search. The example works offline. The relevant excerpts from Prism’s private source are included in the lesson. Following a link to the full repository requires access.
