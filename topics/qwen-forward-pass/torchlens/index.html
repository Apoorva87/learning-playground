    Two reductions, two axes

    256 features → 1 score

    For each key, multiply its 256 coordinates by the query’s coordinates and sum. Multiply the score by 1/16 before softmax.

    17 positions → 1 value

    For each output coordinate, multiply 17 values by their attention weights and sum. Repeat for all 256 coordinates in each of 24 query heads.

    Reading the evidence

    What each measurement tells you

    Bytes and copies

    The inspector shows each output’s logical size and TorchLens’s shape-based read/write estimate. The transpose changes strides and exposes 408 KiB while TorchLens assigns 0 B read and 0 B written. The two repeats each contain an observed aten::clone and produce 408 KiB of expanded FP32 keys or values. Allocator events and DRAM traffic require separate measurements.

    Dependency and time

    The key and value expansion branches can start independently. The first matrix multiplication waits for keys and the query. The second waits for both weights and values. The graph records dataflow, and the replay used one CPU thread. Instrumented call durations include tracing effects. Inspect a timeline to investigate overlap and scheduling.
