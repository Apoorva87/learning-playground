How these numbers are made, and what they cannot tell you

Graph. The nodes and edges are the 17,469 operation records TorchLens captured for one 16-token prefill and one cached decode of the real Qwen3.8-27B architecture ( notes ). Metadata-only ops (views, slices, transposes, no-op casts) are drawn as edges, and operations that depend only on weights or constants are left out, so the picture holds only the work that depends on the token. The unit counts appear under the cards.

Cost. FLOPs and bytes come from tensor shapes alone. A linear layer is 2·tokens·K·N FLOPs and reads its K·N weights once. Every other op reads all of its inputs and writes its output once, as if nothing were fused or cached. They are logical counts, not hardware counters. Elementwise ops count one FLOP per element and exp, sigmoid, silu, rsqrt and similar count four.

Column = dependency step. A node's step is one more than the latest of its inputs, which is the earliest it could start with unlimited hardware. The time readout comes from a roofline: each op takes the larger of FLOPs ÷ peak compute and bytes ÷ peak bandwidth, plus an optional launch overhead. The peaks are vendor numbers, not measurements of this run. Pick a machine, or set the overhead, to see how the critical path moves.

What a column cannot show. A big matrix multiply is a single node, but inside it millions of multiply-adds are independent. The graph shows parallelism between operations. Node size shows how much work hides inside each one. Both matter for hardware: the first is limited by the model's structure and the second by the chip.

Why no measured time? The reference run on a CPU spent 18.8 of its 19.1 decode seconds inside the reference convolution and recurrent implementations of the recurrent layers, which says more about that implementation than about the model. This view stays independent of any one kernel.

The story so far. One decoder block in 3D → where a real run spent its time → five tools on one attention core → the whole pass as a dependency graph (you are here). Each step zooms out from the one before.
